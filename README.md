# 📊 ShopEase Marketing Data Analysis

A complete data analysis project on digital marketing campaigns 
using Python, Pandas, Matplotlib and Seaborn.

---

## 🏢 About the Project

ShopEase is a retail e-commerce company running multiple digital 
marketing campaigns. This project analyzes campaign performance 
to find the best channels, regions, and monthly trends.

---

## 🎯 Objectives

- Find which channel generates highest revenue
- Analyze Return on Advertising Spend (ROAS)
- Study monthly growth in conversions
- Compare performance across regions
- Identify best performing marketing channels

---

## 📁 Dataset

- **Source:** YBI Foundation
- **Records:** 1000 rows
- **Time Period:** January 2025 – December 2025
- **Columns:** Date, Channel, Region, Ad Spend, Impressions,
  Clicks, Conversions, Revenue, CTR, Conversion Rate

---

| Tool | Purpose |

---

## 📊 Analysis Performed

- ✅ Channel wise Revenue & ROAS Analysis
- ✅ Region wise Performance Analysis
- ✅ Monthly Revenue Trend
- ✅ Ad Spend vs Revenue Comparison
- ✅ Region x Channel Heatmap

---

## 📈 Key Insights

- **Best Revenue Channel:** Email Marketing
- **Best ROAS Channel:** Google Ads — 37.6x return
- **Best Region:** East Region
- **Total Revenue:** ₹916.6 Million
- **Overall ROAS:** 33.5x
